# TheValheimWiki

A realtime map of your Valheim server in a browser, with the Realtime Map from seed companion mod.

![The connected Valheim map showing the player and nearby creatures](https://raw.githubusercontent.com/valheim-wiki/live-seed-map/main/listing/screenshots/map-player.png)

Game data at thevalheim.wiki, including creature stats and drops.
